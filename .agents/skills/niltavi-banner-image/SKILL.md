# Niltavi Banner image prompts

Choose the matching prompt. Each prompt works on its own in an image model.

| Style | Prompt | Repository example |
| --- | --- | --- |
| Geometric screenprint / 几何丝印 | [geometric-screenprint.md](references/geometric-screenprint.md) | [Color proof](../../../docs/assets/generator-preview.png) |
| Folk rubber stamp / 民艺橡皮章 | [folk-rubber-stamp.md](references/folk-rubber-stamp.md) | [Stamp proof](../../../docs/assets/stamp-preview.webp) |
| Modernist woodcut / 现代主义木刻 | [modernist-woodcut.md](references/modernist-woodcut.md) | [Black woodcut proof](../../../docs/assets/woodcut-preview.webp) |

Pass the prompt body to the image model. Customize the subjects, count, and format when the user specifies them. For an individual motif, replace the sheet layout with one centered, standalone design. State any required subject order explicitly and check the count and spacing after generation.

Use the most recent user-selected image as the visual authority when it differs from a repository example. Identify each reference's role, such as layout, tool marks, or subjects. For a new series, develop new silhouettes in the selected visual language. For a revision, preserve the parts of the supplied artwork the user has kept in scope.
