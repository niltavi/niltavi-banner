# Niltavi Banner

[English](../README.md)

Niltavi Banner 为 Niltavi 项目生成带丝网印刷肌理的几何图案。种子决定 24 个图案的组合，线条起伏和油墨颗粒可以单独调节。

在本地仓库打开 [index.html](../index.html)，即可离线预览并导出 1024 × 1536 PNG。要在其他项目中生成海报或运行测试，可查阅[集成指南](en/for-agents.md)。

项目采用 [AGPL-3.0](../LICENSE) 许可。
