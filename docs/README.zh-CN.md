# Niltavi Banner

[English](../README.md)

Niltavi Banner 用种子生成插画，可以在现代浏览器中离线运行。

打开[几何丝印](../index.html)，生成 24 格四色几何海报。打开[民艺橡皮章](../stamps.html)，生成暖米白纸上错落排开的四枚深墨绿印章。默认种子「林间」对应银杏叶、蜗牛、蘑菇和橡果。输入 [50 种图案](stamp-motifs.md)中的任意编号，可把该图案放在第一枚。

<img src="assets/generator-preview.png" width="360" alt="几何丝印预览，种子 2564 和四列六行几何图案海报" />
<img src="assets/stamp-preview.webp" width="360" alt="民艺橡皮章预览，暖米白纸上印有深墨绿的银杏叶、蜗牛、蘑菇和橡果" />

在其他项目中调用生成器或运行测试，可查阅[集成指南](en/for-agents.md)。
