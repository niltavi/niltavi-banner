# Niltavi Banner

[English](../README.md)

Niltavi Banner 用种子生成插画，可以在现代浏览器中离线运行。

打开[几何丝印](../index.html)，生成 24 格四色几何海报。打开[民艺橡皮章](../stamps.html)，生成六行四列的 24 枚深墨绿印章，相邻列在竖向略微错开。默认种子「林间」的首行是银杏叶、蜗牛、蘑菇和橡果。输入 [50 种图案](stamp-motifs.md)中的任意编号，可把该图案放在第一枚。

<img src="assets/stamp-preview.webp" width="360" alt="深墨绿民艺橡皮章错落排成六行四列" />

在其他项目中调用生成器或运行测试，可查阅[集成指南](en/for-agents.md)。
