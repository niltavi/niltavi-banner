# Niltavi Banner

[English](../README.md)

Niltavi Banner 用种子生成插画，可以在现代浏览器中离线运行。

打开[几何丝印](../index.html)，生成 24 格四色几何海报。打开[民艺橡皮章](../stamps.html)，生成六行四列的 24 枚深墨绿印章，相邻列在竖向略微错开。默认种子「林间」的首行是银杏叶、蜗牛、蘑菇和橡果。输入 [50 种图案](stamp-motifs.md)中的任意编号，可把该图案放在第一枚。

打开[木刻版画](../woodcut.html)，生成米白纸上的黑色木刻图案。宽刀口交代形体，成簇的短刻痕顺着墨块走势收尖。排版间距沿用民艺橡皮章。[木刻图案目录](woodcut-motifs.md)收录了 50 张独立的透明底 PNG 和对应的种子编号。

[第二辑](series-2.md)为每种风格新增 50 张透明底 PNG。在预览地址后加上 `?series=2`，即可用原有间距预览新图案。
